# NetBox

Source of truth for network infrastructure: starts here as IPAM (IPv4/IPv6 prefixes, subnets, VRFs, VLANs) so OPNsense segmentation and VM addressing stay documented and non-overlapping — with room to grow into full DCIM (racks, devices, cabling) and other capabilities (circuits, service mappings) as the lab expands.
